# AWS Serverless Notes API

REST API built with AWS serverless stack.

## Stack
- AWS Lambda (Python 3.14)
- API Gateway REST
- DynamoDB (On-demand)
- IAM least privilege role

## Endpoints
- POST /notes — create a note
- GET /notes — get all notes

## Live API
https://gjkl6ibugd.execute-api.us-east-1.amazonaws.com/prod/notes

## What I learned
- Serverless architecture on AWS
- Lambda Proxy Integration with API Gateway
- DynamoDB schema design
- IAM roles and trust policies
